The Touch ID and keychain helper is now signed with an Apple Developer ID, so future updates stop asking for keychain access.

- **New:** `AgentBridge.app` is signed with the project's Apple Developer ID. macOS now trusts the signer rather than one exact build, so updates keep their keychain access without asking again. Touch ID asks at the same moments as before, with the same dialog.
- **Docs:** the troubleshooting guide explains the one-time keychain prompts after this upgrade.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. **One last round of keychain prompts:** the first time the signed helper reads each saved secret, macOS asks "AgentBridge wants to use your confidential information stored in "agentbridge" in your keychain", once per item (about 7). Enter your login password and choose **Always Allow**. New installs see none of these.

`npm install -g @musi27/agentbridge@0.2.6`
