A quieter keychain upgrade from 0.2.6, and no more password prompts at every start.

- **Fixed:** upgrading from 0.2.6 to 0.2.7 could ask for your login password many times and leave old keychain items behind, which then asked again at every bridge start. 0.2.8 reads each old item at most once, and only if its key isn't in `agentbridge: saved keys` yet. It never asks again on later starts.
- **Fixed:** if macOS refuses to delete an old item, AgentBridge leaves it and carries on instead of stopping.
- **New:** `agentbridge doctor` has a keychain check that lists any old items left, with the command to delete each one: `security delete-generic-password -s agentbridge -a <name>`.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. If you're on 0.2.7 and see a password prompt at every start, this fixes it. Run `agentbridge doctor` afterwards to see whether any old items are left.

`npm install -g @musi27/agentbridge@0.2.8`
