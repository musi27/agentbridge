The menu-bar panel gets a window that shows who your agents are talking to.

- **New:** a graph window, opened from the panel's **Window** button (⌘O) or its ••• menu. Each project or app is a bubble with its app icons and counts; lines show who is talking to whom, with an arrow for who started it and `6/12 turns · 3m` when zoomed in. A dashed coral line is an invitation or a "more turns" request waiting on you. Click a line to see that conversation's approvals and turns over time. Zoom in for a card per agent, drag bubbles to arrange them (View → Reset Layout puts them back), and switch to a list from the toolbar. It follows the Mac's light or dark mode, or you can pick one. Like the panel it's read-only: no approvals, no message text.
- **New:** `agentbridge status --json` lists each conversation's last 50 turns as `turn_log`: turn number, sender and time, never the message. The field is additive; see `docs/status-json.md`.
- **Fixed:** an agent waiting only on a "more turns" approval is tagged "more turns?" in the panel, not "invited".
- **Fixed:** `agentbridge status --watch` fits the terminal's height. In a short window it shortens the agent list, then notices, then conversations, with "+ N more" lines, so the header and WAITING ON YOU stay on screen instead of scrolling away.
- **Docs:** the README's "Menu-bar panel" section describes the window.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. The window is in the panel after `init`.

`npm install -g @musi27/agentbridge@0.3.0`
