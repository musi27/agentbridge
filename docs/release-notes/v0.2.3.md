Grok can search the web and X inside a conversation; Codex hooks get names.

- **New:** Grok may use its own read-only web and X search when a question needs current information. Its chat report says what it searched for. Queries never carry secrets, tokens, links from the message or private details.
- **New:** `bridge_list_agents` marks your own session `self: true`, listed first (Claude Code and Codex).
- **New:** Codex's `/hooks` shows agentbridge's 5 hooks as "agentbridge: …" instead of "Unnamed hook".
- **Fixed:** `init` and `add codex` no longer drop Codex's hook trust when they refresh the Codex setup.
- **Fixed:** Grok won't delete an old connector, so `add grok` and `uninstall` now send you to grok.com/connectors to remove it, and the setup prompt tells Grok to stop instead of adding a second one.
- **Docs:** search risks in `docs/security.md` and the README privacy section; a troubleshooting entry for when Grok refuses or offers a second connector.
