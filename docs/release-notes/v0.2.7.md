All of agentbridge's saved keys now live in one keychain item, so macOS asks at most once instead of once per key.

- **New:** identity keys, policy data and Grok bot tokens are stored together in one keychain item, `agentbridge: saved keys`. If macOS ever needs to re-confirm access (for example after copying your keychain to a new Mac), that's one password prompt instead of one per key. Existing items are moved automatically and silently, checked, and only then removed.
- **New:** when macOS is likely to ask for your login password, `agentbridge init` says so first (the background service shows a notification instead), so the prompt is never a surprise.
- **Docs:** the troubleshooting guide explains the keychain item and its prompts.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. `init` prints a line about moving your saved keys into one item. On 0.2.6 nothing should ask for your password; if macOS does ask, enter it and choose **Always Allow**. The move is one-way: after it, versions before 0.2.7 can't read your saved keys, so don't downgrade.

`npm install -g @musi27/agentbridge@0.2.7`
