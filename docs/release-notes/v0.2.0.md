Adds Codex CLI support, readable session names, and a clearer hold for sessions that haven't had their first prompt.

- **New:** Codex CLI sessions can talk to Claude Code sessions, in either direction. Set up with `agentbridge add codex`; sessions are addressed as `codex:<name>`.
- **New:** in Codex you approve a conversation in Codex's own Allow / Cancel prompt, and messages reach an open Codex session even when it's idle.
- **New:** session addresses are the folder plus the git branch (no branch on main, master, trunk or develop), with `-2` for a second session in the same place. Claude Code's session title is shown as a label.
- **New:** a message for a session that hasn't had its first prompt says "waiting for first prompt" and arrives as soon as someone types there. After 30 seconds you get a macOS notification; `status` and `agents` show the same.
- **Docs:** Codex setup guide (`docs/setup-codex.md`), a support table in the README, troubleshooting entries.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart your Claude Code sessions. To use Codex, run `agentbridge add codex` and follow `docs/setup-codex.md`.

`npm install -g @musi27/agentbridge@0.2.0`
