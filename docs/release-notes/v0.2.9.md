AgentBridge now lives in your menu bar, and `agentbridge status` can stream JSON.

- **New:** a menu-bar panel. Its icon shows a count when an approval or a held message waits on you. Click it to see where to answer each one, the conversations between your agents (topic, turns, and who approved them, how and when) and all your agents, grouped by project or by app. It's read-only: approvals stay in each agent's own prompt. `agentbridge init` starts it at login.
- **New:** to turn the panel off, choose **Turn off menu-bar panel** from its ••• menu or run `agentbridge panel stop`. It stays off after upgrades until you run `agentbridge panel start`. `agentbridge init --skip-panel` skips it, and `agentbridge uninstall` removes it.
- **New:** `agentbridge status --json` prints one versioned snapshot, and `agentbridge status --watch --json` streams one line per change, for scripts and other tools. Agents are grouped by git repository, shown as a hashed key, and the output contains no absolute paths. Each conversation shows how it was approved: at the prompt, from the command line, by an allow rule or by a bot.
- **Docs:** the README has a "Menu-bar panel" section, `docs/status-json.md` describes the JSON fields, and `docs/troubleshooting.md` covers turning the panel off or finding it when it doesn't show. `SPEC.md` is now a public design document.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. The panel appears in the menu bar after `init`. The bridge's database is upgraded on first start; going back to 0.2.8 afterwards isn't supported.

`npm install -g @musi27/agentbridge@0.2.9`
