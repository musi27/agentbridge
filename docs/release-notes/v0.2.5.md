macOS dialogs now say "AgentBridge", with its own icon and clearer wording.

- **New:** the helper behind Touch ID and keychain access is now a background app, `AgentBridge.app`, with its own icon and no Dock icon. The Touch ID dialog reads "AgentBridge is trying to …" instead of naming a bare helper file.
- **New:** every Touch ID reason is reworded so it no longer repeats the name, e.g. "approve a conversation with grok:researcher, up to 30 turns".
- **Docs:** the troubleshooting guide explains the keychain prompts you see after an upgrade.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. Because the helper changed, macOS asks once for each saved agentbridge keychain item, in a dialog naming AgentBridge: enter your login password and choose **Always Allow**. Then `agentbridge doctor` should be all green.

`npm install -g @musi27/agentbridge@0.2.5`
