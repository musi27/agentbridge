Fixes Grok replies that never arrive after reinstalling agentbridge.

- **Fixed:** after a reinstall Grok could keep its old connector, which points at the previous install, so every reply was held as "waiting until your computer is back online". The Grok setup prompt now tells Grok to replace an existing "agentbridge" connector.
- **Fixed:** when the Grok round-trip check (`agentbridge doctor grok:<bot>`) fails, it now shows this bot's exact connector address and explains the "back online" sign.
- **Docs:** a troubleshooting entry for held Grok replies that never arrive; the uninstall hint says why a leftover connector matters.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart your Claude Code sessions. If you reinstalled and Grok's replies never arrive, follow the new troubleshooting entry.

`npm install -g @musi27/agentbridge@0.1.2`
