Makes upgrading easy: `init` now restarts a bridge that is running an older version.

- **New:** `agentbridge --version` (also `-v`) prints the version, and notes when the running bridge is a different one.
- **New:** `agentbridge init` restarts a running bridge on another version. Your settings, identity and conversations are kept. It also refreshes the Codex setup if you ran `add codex`.
- **New:** `doctor` and `status` warn when the CLI and the running bridge are different versions.
- **Fixed:** the Claude Code plugin's version now follows the release version.
- **Docs:** an Upgrade section in the README and a troubleshooting entry.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code sessions (or run `/reload-plugins`) and Codex sessions. Check with `agentbridge --version` and `agentbridge doctor`.

`npm install -g @musi27/agentbridge@0.2.1`
