A live agent panel in the terminal, and a clearer approval prompt in Codex.

- **New:** `agentbridge status --watch` is a live panel that redraws until Ctrl-C: what's waiting on you (approvals, held messages), conversations with topic and turns, and live agents. Read-only, no Touch ID. Without a terminal it prints one snapshot.
- **Fixed:** Codex's approval prompt now shows who the conversation is with, the topic and the turn limit (`agent`, `about`, `allowed_turns`), and agentbridge checks them against the approval. Topics over 60 characters appear cut short.
- **Docs:** `docs/security.md` explains when outgoing messages are and aren't prompted (Claude Code default and auto mode, Codex), and that repeated injection attempts can make a session's safeguards pause it.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart open Claude Code and Codex sessions. Codex may ask you to trust agentbridge's hooks again.

`npm install -g @musi27/agentbridge@0.2.4`
