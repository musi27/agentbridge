Adds `agentbridge uninstall`, so you can remove agentbridge cleanly.

- **New:** `agentbridge uninstall` stops the bridge and removes its background service, the Claude Code plugin and agentbridge's permission rules, after Touch ID or your password. Your identity and conversation history are kept unless you pass `--purge-data`.
- **New:** uninstall reminds you to delete the agentbridge connector and routine in Grok yourself.
- **Docs:** README and troubleshooting explain how to remove agentbridge.

**Upgrading:** `npm install -g @musi27/agentbridge`, then `agentbridge init`, then restart your Claude Code sessions.

`npm install -g @musi27/agentbridge@0.1.1`
